
# Inventory Management System - Single User

A browser-based inventory management system built using:

- HTML
- CSS
- JavaScript
- Browser LocalStorage

## Features

- Single-user signup and login
- Password hashing
- Browser-based data storage
- No PHP
- No MySQL
- No backend server
- GitHub Pages compatible

## Installation

1. Download or clone this repository.
2. Open index.html or publish the repository using GitHub Pages.
3. Create your account.
4. Login to access the inventory dashboard.

## Storage

All application data is stored locally in the browser using LocalStorage.

Clearing browser data may permanently delete the saved information.
